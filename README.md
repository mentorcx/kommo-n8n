# Kommo CRM + n8n — Centro de recursos

[English version](README.en.md)

Wiki colaborativa sobre la **API de Kommo CRM** y su uso con **n8n**. El objetivo es organizar conocimiento abierto: explicaciones de endpoints, restricciones, patrones de integración y flujos de n8n listos para importar.

## Idiomas

Idioma fuente: **Español (`es`)**. Las traducciones viven en `docs/<idioma>/` y los archivos de flujos usan sufijo (`README.es.md`, `README.en.md`). El estado de cada traducción se lleva en [`TRANSLATIONS.md`](TRANSLATIONS.md).

## Cómo contribuir

Lee [`CONTRIBUTING.md`](CONTRIBUTING.md). En resumen:

1. Haz fork y crea una rama descriptiva.
2. Añade o edita el contenido en markdown siguiendo las plantillas.
3. Si tu cambio afecta varios idiomas, actualiza `TRANSLATIONS.md`.
4. Abre un Pull Request.
