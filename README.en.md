# Kommo CRM + n8n — Resource hub

[Versión en español](README.md)

Collaborative wiki on the **Kommo CRM API** and its use with **n8n**. The goal is to organize open knowledge: endpoint explanations, restrictions, integration patterns, and ready-to-import n8n flows.

## Languages

Source language: **Spanish (`es`)**. Translations live in `docs/<lang>/` and flow files use a suffix (`README.es.md`, `README.en.md`). Translation status is tracked in [`TRANSLATIONS.md`](TRANSLATIONS.md).

## How to contribute

See [`CONTRIBUTING.md`](CONTRIBUTING.md). TL;DR:

1. Fork and create a descriptive branch.
2. Add or edit markdown content following the templates.
3. If your change affects multiple languages, update `TRANSLATIONS.md`.
4. Open a Pull Request.
